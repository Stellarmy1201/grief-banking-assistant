# Grief Banking Assistant

A conversational assistant that guides bereaved Westpac customers through notifying
the bank, one gentle question at a time. It keeps a live record of each conversation
and gives the user a session code so they can leave and come back later.

Stack: Flask + Google Gemini, MySQL (SQLAlchemy + Alembic migrations), all run with Docker.

## What you need

- **Docker Desktop** (running). That is all that is required to run the app.
- A **free Gemini API key** from https://aistudio.google.com (each person uses their own).

You do not need Python or MySQL installed locally. Docker provides both.

## Quick start

1. **Clone and enter the repo**

   ```bash
   git clone https://github.com/Stellarmy1201/grief-banking-assistant.git
   cd grief-banking-assistant
   ```

2. **Create your `.env`** from the example (it is not committed, so you make your own):

   ```bash
   cp .env.example .env
   ```

   Open `.env` and paste your Gemini key:

   ```
   GEMINI_API_KEY=your-key-from-aistudio
   ```

   Leave the `DB_*` lines as they are. They already match the database container.

3. **Start everything**

   ```bash
   docker compose up --build
   ```

   First run pulls MySQL and builds the app (a minute or two). The app waits for the
   database, applies the migrations automatically, then starts.

4. **Open the app**

   http://localhost:8080

To stop it, press `Ctrl+C`, or from another terminal:

```bash
docker compose down
```

## How it works

- **Start a new conversation** gives you a session code like `WBC-Q9M2J9`. The code is
  generated by the server and the whole conversation is saved in MySQL under it.
- **Resume** with that code reloads the conversation from the database.
- **Book an appointment**: the "Book an appointment" button opens a panel to pick a branch
  and an available time. The booking is saved and shown in the chat (and survives resume).
- If Gemini is busy or no key is set, the app still runs and saves messages; it just
  replies with a short "please try again" instead of an AI answer.

## Admin panel

Staff can review activity at **http://localhost:8080/admin** (password from
`ADMIN_PASSWORD` in `.env`, default `admin` for local). It has three sections:

- **Conversations** — every session, click through to the full transcript.
- **Appointments** — all bookings, with a Cancel action that frees the slot.
- **Branches & Availability** — add or remove branches and their bookable time slots.

Demo branches and slots are seeded automatically on first run, so there is data to show.

## Everyday commands

Follow the app logs:

```bash
docker compose logs -f web
```

Rebuild after changing `requirements.txt`:

```bash
docker compose up -d --build
```

Database migrations (run inside the container):

```bash
docker compose exec web flask db migrate -m "describe your change"
docker compose exec web flask db upgrade
```

## Connecting to the database

The MySQL container is published on **port 3307** on your machine (3306 is left free in
case you run another MySQL). Use these in a client like TablePlus or DBeaver:

| Field    | Value             |
|----------|-------------------|
| Host     | `127.0.0.1`       |
| Port     | `3307`            |
| User     | `grief`           |
| Password | `griefpw`         |
| Database | `grief_assistant` |

Command line:

```bash
mysql -h 127.0.0.1 -P 3307 -ugrief -pgriefpw grief_assistant
```

## Troubleshooting

- **Port 8080 already in use**: stop whatever is using it, or change the `web` port
  mapping in `docker-compose.yml` (e.g. `"8081:8080"`) and open that port instead.
- **"AI offline" or "having trouble responding"**: your `GEMINI_API_KEY` is missing or
  Gemini is overloaded. Check the key in `.env`, then `docker compose up -d web`.
- **Database errors on first start**: make sure Docker Desktop is running, then
  `docker compose down` and `docker compose up --build` again.

## Notes

- `.env` holds your secret key and is **not** committed. Never commit it.
- Everything is for a hackathon prototype. The Flask dev server is fine here, but it is
  not meant for production.
